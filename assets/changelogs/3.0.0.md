# Version 3.0.0 Update 🚀


### ✨ Reworked Interface
* **One Menu Everywhere:** Every page now shares the same menu. On phones it opens from the menu button; on tablets the side bar stays visible next to the page.

* **Automatic Updates:** Lists and reports now update on their own as soon as something changes, so the refresh buttons are gone.

* **Clearer Forms:** Adding and editing a person or a daily entry now use the same form, so the fields always look and behave the same. The edit page is now titled "Edit Person".


### 🆕 New Features
* **Storage Access Screen:** If Attendly is not allowed to access your files yet, a screen explains why it is needed. After you allow access in the system settings, the app continues on its own.

* **Faster Start:** The Attendly logo is shown while the app starts, and the loading screen only appears while there is real work to do.

* **Show Logs:** If a database cannot be opened, the error screen now has a "Show logs" button, so problems can be reported more easily.


### ⚡ Performance
* **Large Databases:** The daily log loads faster when there are many entries. Your database is upgraded automatically the first time you open it with this version.

* **Directory Search:** The directory search now waits until you stop typing, which keeps long lists smooth.



### 🔮 Looking Ahead
* We keep improving Attendly. Feedback and ideas are always welcome!
