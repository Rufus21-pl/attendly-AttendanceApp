# Version 3.1.0 Update 🎨


### ✨ Refreshed Design
* **Side Menu:** A new header shows the open database, its year and whether it is your main database. The menu items are easier to tell apart, and the app version is shown at the bottom.

* **New Year Banner:** When a new year is ready to be set up, a colourful banner in the menu points you to it.

* **Forms:** Gender, migration and category are now chosen with chips instead of drop-down lists. The home country field only appears when it is needed. The Reset and Save buttons no longer squeeze their text on phones.

* **Daily Log:** The date selector shows the weekday, each person has a name badge, and every entry shows its category icon. The filter options have chips, a counter for active filters and a Reset button. The menu behind the three dots has icons.

* **Search:** The daily log search uses chips, shows its results grouped by day and starts the search from the keyboard as well.

* **Weekly Report:** The date selector has the same size as in the daily log and shows the calendar week. In the week list, a switch shows and changes whether a week counts towards the year report.

* **Settings:** Grouped into Appearance, Data and About. The language is picked with a simple English | Deutsch switch. The database picker highlights the database that is open.

* **Messages and Dark Mode:** Notifications have a new look with an icon. Cards, numbers and the debug information are easier to read in dark mode.


### 🆕 New Features
* **Jump to Today:** The daily log and the weekly report have a button that takes you back to today or to the current week.

* **Database Switch Feedback:** When you open another database, a short loading screen and a message confirm which database is now open.

* **Duplicate Names:** If a person with the same name already exists, a warning appears right under the name field while you type.


### 🐞 Bug Fixes
* The weekly report keeps the selected week when you switch to another page and come back.

* Dialogs now always use the language you selected.

* The daily log buttons no longer fly in from the middle of the screen.

* The daily log date picker is enlarged on tablets like the other date pickers.

* The week list is fully translated.
